# Table density

Results, enemy participants, target tracks and recent session battles share a
compact spacing pass. Activity event entries follow the same rhythm. The change
reduces vertical padding and metadata gaps without reducing font sizes, changing
the responsive root scale, clipping names or hiding reported data.

Results keep outcome and timestamp on one line when there is room, wrapping on
narrow panels. Header icons sit beside their labels, with wrapping still allowed
for Russian labels and enlarged text. AI counts remain separate from player kills
and are shown alongside the kill count when they fit. Expanded details, team and
damage colors, loss markings, keyboard focus, and scrollable table containers are
unchanged. Empty states use a smaller amount of space.
